- T1-CONTINUE-GOAL-2: `GoalController.continueCard(runner, goalId, card, act)` continues a card on its existing run through `CardRunner.continueStop` and, when `aidlc next` stopped the goal for the reason of the lifted stop, re-admits the goal with one `GOAL_STATE` from `STOP` to `CARDS` carrying `continuation` (`cardId`, `by`). A refusal (a refused goal, a blank `by` or `reason`, `decisions` outside 1 to 4, a card with no run, a run the runner refuses) changes no record; a failure after the runner's write is thrown and nothing is undone, so `aidlc card next` delivers an owed event and the next call completes the re-admission without a second continuation. The command `aidlc card continue` arrives with T1-CONTINUE-COMMAND.
