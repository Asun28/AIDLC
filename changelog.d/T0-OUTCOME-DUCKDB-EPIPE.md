- T0-OUTCOME-DUCKDB-EPIPE: `node bench/outcome/run.ts` exits 2 with the install hint only when no DuckDB process started (an error with neither an exit code nor a signal); a binary that started and exited with a failure, also when it exits before its input is written (`EPIPE`, or `EOF` on Windows), is exit 1 with its exit code, its stderr and the error of the write. Before, any `spawnSync` error without a signal was read as a binary that cannot be started, and `tests/surface/outcome-ingest.test.ts` acceptance 10 failed in CI when the stand-in binary exited before the write (issue 435). The call is `queryDuckdb` in the new `bench/outcome/duckdb.ts`, covered by `tests/surface/outcome-duckdb.test.ts`.
