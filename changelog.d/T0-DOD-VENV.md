- T0-DOD-VENV (bugfix, issue 450): the loop-run DoD of `aidlc card attempt --outcome success` runs the `dod_command` with the scripts directory of a Python virtualenv first on `PATH`, `VIRTUAL_ENV` set and `PYTHONHOME` removed, when the card worktree or else the main checkout holds `.venv` or `venv` with a `pyvenv.cfg`; the DoD runs of `aidlc card mutants` look in the card worktree. Before, the loop's DoD inherited the loop's `PATH`, so in a Python repository it used the system `python` and failed at import where the worker's DoD with the virtualenv active passed. The `loopDod` record names the virtualenv in `virtualenv`. A repository with no virtualenv in those directories runs the DoD as before.
