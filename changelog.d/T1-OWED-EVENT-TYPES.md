- T1-OWED-EVENT-TYPES: a card-run write can owe a `CARD_STATE` event to the goal journal, owed by the write that records the continuation of a stopped run (card T1-CONTINUE-REVIEW), and a `NOTE` event, owed by the write that records the amendment of a started card (card T1-CARD-AMEND); the `OwedEvent` schema accepted neither type before, and the delivery and matching of an owed event are unchanged.
