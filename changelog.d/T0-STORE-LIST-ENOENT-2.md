- T0-STORE-LIST-ENOENT-2 (bugfix, issue 368): a state directory is listed as empty only when listing it fails with `ENOENT`. Any other failure, such as a parent directory that cannot be searched (`EACCES`) or a parent that is a regular file on POSIX (`ENOTDIR`), is `READ_FAILED` naming the directory, where `listJsonFiles` and `findInterruptedWrites` answered an empty list because `existsSync` could not see it. So the production gate refuses an approval that matches no recorded production authorization when the goals directory cannot be listed, where it let the command run as if there were no aidlc state; `aidlc doctor` reports an uncommitted planning file as `claim unknown (goal records unreadable: READ_FAILED)` in that case, where it said `unclaimed`; and every command that lists goals, card runs, release attempts, operations or review requests refuses such a directory. On Windows a directory under a regular file reports no entry and still lists as empty.
