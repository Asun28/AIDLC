- T1-CONTINUE-CORE: a card run holds `continuations` (`at`, `by`, `reason`, the lifted stop's `reason`, `detail` and `at`, optional `decisions` and `admits`), empty by default. The pure `continueReviewStop` (`src/core/continuation.ts`) lifts every unlifted `stopReview` of a run stopped for review and returns the entry with `admits` equal to the recorded decisions plus `decisions` (1 to 4, 1 when absent); it refuses a run not stopped for review, a reviewer that is not a command, a stop on a missing verdict, a blank `by` or `reason` and any other `decisions`. `admittedDecisions` reads the `admits` of the last review continuation, and `recordReviewOutcome` given that count compares a command reviewer's block with it in place of the four-decision cap, naming the continuation in the stop detail; the re-raise stop and ship-path decisions are unchanged. No caller uses them yet.
