# T0-BUILD-ATOMIC

## Deliverable
`npm run build` runs `node scripts/build.ts`. The script compiles `tsconfig.json` with the TypeScript compiler API, the same program and options as `tsc -p tsconfig.json`, and writes each output to a temporary sibling (named by `tempName`, src/state/store.ts) renamed onto it, so a reader sees the whole earlier file or the whole new one; a rename Windows refuses while another process reads the file is retried for up to 2 s. It writes `hooks/entry.js` and `cli/main.js` after every other output, so the moment an entry becomes newer than the sources, every module it loads is already this build's output. Until now tsc emptied each output and then wrote it, and a hook started during the build could load an empty module: a PreToolUse guard then exited 1 with no deny, and the routing guard printed nothing. The script honours `-p` and `--outDir`, prints diagnostics in tsc's format and exits with tsc's codes.

## Doc text
- OPERATIONS: `npm run build` runs `scripts/build.ts` (card T0-BUILD-ATOMIC), which compiles the program of `tsconfig.json` as `tsc -p tsconfig.json` does and writes each file of dist/ to a temporary sibling renamed onto it, `hooks/entry.js` and `cli/main.js` last, so a hook or CLI process started during a build loads the whole earlier module or the whole new one. A rename Windows refuses while another process reads the file is retried for up to 2 s, and a write that still fails stops the build there, so an entry is written only after every module it loads. Under `tsc` a hook could load a module emptied for its rewrite: a PreToolUse guard then exited 1 with no deny and the routing guard printed nothing. A bare `tsc` still writes dist/ in place.
- CHANGELOG: - T0-BUILD-ATOMIC (bugfix): `npm run build` runs `scripts/build.ts`, which emits the files `tsc -p tsconfig.json` emits with the same bytes, each written to a temporary sibling and renamed onto it, and the two compiled entries last. Before, tsc emptied each file of dist/ before writing it, so a hook started during a build could load an empty module and run no guard: a denied write went ahead, and a typed request got no routing line.
- CLAUDE.md: `npm run build                  # scripts/build.ts: tsc -> dist/, each file written whole (rewrites .ts imports to .js)`
- README: `npm run build        # scripts/build.ts: tsc -> dist/, each file written whole`
