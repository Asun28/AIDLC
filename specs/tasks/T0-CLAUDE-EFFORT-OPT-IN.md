# T0-CLAUDE-EFFORT-OPT-IN

## Deliverable
A config key `claudeCode.forwardEffort`, off by default. When it is on, the `claude-code` provider passes the request's effort as `--effort <level>` after `--model`, for `aidlc run` and for `aidlc evals run`, and refuses the call, starting no process, while a key named `CLAUDE_CODE_EFFORT_LEVEL` (any letter case, any value) is in the launch environment of the claude process. When disabled, aidlc does not synthesize an effort argument; existing extra arguments, environment and Claude Code settings remain effective, and the argv is today's.

## Why
Audit of 2026-11-11, item C12; two consultants analysed it and disagreed (forward always, or behind a key), and the coordinator ruled on 2026-11-12 for the key, off by default. A request names an effort and the `claude-code` provider drops it, so `aidlc run` and a model eval can return ok without applying the requested effort; forwarding it changes the cost of every call, so it is the user's choice.
