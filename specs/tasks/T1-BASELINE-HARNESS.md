# T1-BASELINE-HARNESS

Deferred on 2026-09-26 and released on 2026-11-09, when the user decided plan decisions D1-D3 again (hygiene). The oracle runs MyInspection's unit tests through Gradle, so the machine that runs a build needs the JDK and Android SDK that repository's README names; the pilot (acceptance 7) proves it. The pilot needs the sandbox repository to exist.

Amended on 2026-11-23, before any run, by the owner's decision in the session (`intent/auto-ontology-study.md`, Decisions, Q1). The changelog entry is the card's own file under `changelog.d/`, as `changelog.d/README.md` requires since T1-CHANGELOG-FRAGMENTS. Each run record carries the SHA-256 of the task list it ran (R2, acceptance 3 and 9), and the generated report states it (R6, R7): a digest taken from the working tree when the report is written would not show which task list the runs used.

Amended on 2026-11-24, before any run, by the owner's instruction in the session (the plan's amendment of that date). The comparison is the pull request review and ship stage, and the control arm is Claude Ship, not plain Claude Code. aidlc builds each task once per run; arm A hands that build's candidate to Claude Ship in a pull request of its own, and arm B is the same card run continued through aidlc's R3 review and ship (R8 to R10, acceptance 10 to 12). The build's usage is recorded apart and is in no arm's figures (R2). Pairs run round by round under a rule that lets a started pair finish inside the total cap (R11), and the generated text names what the pairing adds (R13). The budget rises from 900 to 1200 for the arm A steps and their tests.

The pilot needs Claude Ship to be available to the operator in one of its two forms: its agents enabled on the sandbox repository, or the `/ship` command in a Claude Code session outside native Windows.

## Deliverable
`evals/baseline/` holds a task list of 12 real tasks, a harness that builds each task with aidlc in a fresh checkout, opens the arm A pull request for Claude Ship and continues the card run as arm B, records for the build and for each arm the oracle result, tokens, cost, wall clock, human interventions, end state, the bound that fired and the digest of the task list, and an analysis that reports per-task paired differences and the minimum detectable difference and names that digest. A one-task pilot proves the harness end to end. src/ is unchanged.
