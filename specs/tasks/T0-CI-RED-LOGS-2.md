# T0-CI-RED-LOGS-2

## Deliverable
A red CI run on the GitHub ship path carries the lines of the failed step of each red Actions job, the step bounded by the job record (its start and end times and its own header), so the loop can tell a code defect (a counted repair attempt) from a transient failure (one rerun under the real run id) instead of stopping every red run as unknown. Log text is data: encoded, capped, and never read as a sentinel, a check name, a PR number, a run id or a step boundary.
