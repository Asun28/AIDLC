# T0-BANDS-RULES-REFUSE

## Deliverable
`parseBandsYaml` accepts `rules` only as `western_electric`, which stays the default when the key is absent, and refuses any other value, `threshold` included, with an issue at `rules` that reads `rules: the only supported value is western_electric`. `aidlc monitor check` with such a file exits 1 without evaluating a band or writing anything. The public `BandBreach.rule` type keeps `'threshold'`; no threshold rule is implemented.

## Why

The ruling refuses it at parse time; a downstream file with `rules: threshold` now fails where it ran before.
