## Source expressions
An expression is a JSON pointer, then an optional filter, then an optional tail, read against the file's JSON. labels.jsonl and labels-final.jsonl are each read as the array of its parsed non-blank lines (split at `\n` with a trailing `\r` removed), and their expressions have no pointer.
- Pointer: RFC 6901 (`~1` for `/`, `~0` for `~`), its tokens holding no `[`, `]`, `.` or `#`; empty for the whole document.
- A number or null at the pointer is the source value; such an expression has no filter and no tail.
- An array at the pointer: the filter `[<field>=<v>, ...]` keeps the elements for which every condition holds (no filter, or `[]`, keeps all); conditions are separated by a comma, and spaces around a condition are ignored. `<v>` `null` holds when the field is null or absent; `<v>` that starts with `$` holds when the field is strictly equal to the element's field named by the rest; any other `<v>` holds when `String` of the field equals it. With no tail the value is the count of kept elements; with `.<column>` it is the sum of that column over them, null when every one is null, and at least one element must be kept; with `#<column>` it is the number of distinct values of that column, compared as JSON text.
- Anything else fails the row: a pointer that does not resolve, an object, a filter or tail on a number, a sum over a value that is not a number.
