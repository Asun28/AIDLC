# T1-REVIEW-BENCH-EXPORT

## Deliverable
`aidlc review bench export --card <id> [--goal <id>] [--clean] [--dir evals/review]` turns the review ledgers into draft cases for the reviewer bench: one unconfirmed bug case per formal finding of the card's runs, with the cited file and line, a class and the base the loop's diff started from, and with `--clean` one unconfirmed clean case per card run whose first R3 decision passed. Each written case's candidate is pinned under `refs/aidlc/bench/<case id>`, a local ref that keeps the commit through garbage collection. An existing case is never overwritten, and the command never writes under the state directory. A person confirms a draft before `aidlc review bench run` reviews it.

This card is the export half of plan item 3, split from T1-REVIEW-BENCH. It implements spec R8, spec R9 for the export command, the export clause of spec acceptance 3, and R21 for its own docs.

Decisions:
- Case id: `<card id>.<goal id>.<finding id>`, or `.clean` for a clean case. Six cards ran in more than one goal and finding ids restart per run, so the id carries the goal id; one card run per goal makes the id unique.
- Base: `git merge-base <base.oid, else base.ref, else the configured base> <candidate>`, the rule of T1-REVIEW-BENCH decision 1.
- Window: 5 lines, or the cited range when it is longer, at most 50; the person narrows it on confirmation.
- Class: the reason's `(class: <slug>)` tag, else `dim-<n>` from the REVIEW.md dimension number after the axis tag, else `unclassified`, read from the reason text only.
- Clean selection: per card run, the first entry of `review.invocations` whose outcome is `pass` or `block`; a pass with a `candidateSha` gives one draft. At 597e9a2 that is 49 of 157 card runs, 47 with a `candidateSha`.
- `--card` is required for bug drafts, so a person exports the findings of one card at a time; `--clean` without `--card` covers every card run of the selected goals.
- An existing case or a ref naming the candidate already is left alone, so the export can be run again after a card gains findings.
