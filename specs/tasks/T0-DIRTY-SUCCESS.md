# T0-DIRTY-SUCCESS

## Deliverable
`aidlc card attempt --outcome success` on a card worktree with uncommitted or untracked changes is refused and records nothing. The message names the changed paths. The implementer commits, removes or ignores them and records the success again, and no failure is counted.

## Why
A dirty success is stored today with a succeeded episode. `card next` then returns a BUILD directive that opens no attempt, and a second `card attempt` is refused with `episode already succeeded`. The only exit is `card withdraw`, which counts a failure. A dirty candidate can never be reviewed or shipped, so refusing it removes no supported path. Checked: no ship path, mode or test records or ships a dirty success. The scenario harness uses the `dry-run` path, which never probes, and local mode merges the committed branch.
