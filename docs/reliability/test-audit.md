## Search

Commit searched: `1a757adb` (main, 2026-11-19). Scope: every `*.ts` file under `tests/` (2855 `it`/`test` calls found at the start of a line in `*.test.ts` files, plus the helpers they import). Each angle and what it found:

1. **Superseded cards.** Listed every card under `specs/tasks/` with `superseded_by:` (113 cards; `specs/archive/tasks/` does not exist at this commit) and searched the `it`/`test`/`describe` names under `tests/` for each id as a whole word not followed by `-` (364 matching lines, 57 card ids). In every chain checked, the successor card restates the predecessor's acceptance items and merged the tests under the predecessor's id: for example `T0-R2-FALLBACK` to `-2` to `-3` (acceptance 1 to 7 carried over, 8 added) and `T1-LOOP-GATES` to `T1-LOOP-GATES-2` (same title, "replacement of T1-LOOP-GATES after its two R3 decisions"). The five cards superseded by a card with another id (`T0-CONTEXT-SOURCE-ERRORS`, `T0-HOOK-CONFIG-RACE`, `T1-BOUND-TELEMETRY-6`, `T1-OUTCOME-BASELINE`, `T1-RUN-DRIVER-3`) are named by no test. Result: no `superseded-card` row. A test name that carries a superseded id is a naming fact, not a mismatch with the code.
2. **Removed exports and paths.** Collected the camelCase identifiers and `--flags` in all test names (360 tokens) and looked each up with `git grep` in `src/`, `bin/`, `scripts/`, `templates/`, `.claude/`, `docs/`, `bench/`, `README.md`, `REVIEW.md`, `.github/` and `aidlc.config.json`. The tokens found nowhere outside `tests/` are test-local helpers or were moved out of `src/` by the sweep cards T1-SWEEP-DEAD-CODE (`bb77e2c2`), T1-SWEEP-REVIEW-WRAPPERS (`77b57457`), T1-SWEEP2-DUPLICATES (`dab3abc5`) and T1-SWEEP2-TEST-ONLY (`9d856614`). For each moved function, read every test that calls it: a test that reaches a `src/` function through a thin test wrapper still tests that function and is not listed (for example "runPreReview classifies pass, block, malformed and quota output and writes verdict + log files" tests `finalizeReview`, and "renderSpec re-parses cleanly" tests `parseSpec`); a test whose assertion only the wrapper's own code can satisfy is listed as `removed-path`. Tests that assert a removal (`tests/surface/removed-surface.test.ts`, "renameSources is removed [R3]") pin the current code and are not listed.
3. **Features turned off are not removed.** Checked the tests that read this repository's `aidlc.config.json` (`tests/core/config.test.ts`) and the R2 tests: `preReview` with its fallback is still a config block and a code path (`src/review/pre-review.ts`, `runReviewPanel`); this repository only leaves `preReview.command` empty. No R2 test is listed for that reason.
4. **Duplicates.** Hashed the whitespace-normalised body of every `it`/`test` callback with more than 80 characters (TypeScript AST) and compared; and listed every `assert` statement longer than 90 characters that occurs in two or more test files. The equal bodies and statements found (`docs/OPERATIONS.md` and `CHANGELOG.md` sentence checks, "removing any one sentence from its document fails its check") read file-local constants with different sentences, so they assert different facts. No two tests have the same name. Result: no `duplicate` row.
5. **Skips and silent passes.** Listed every `skip`/`todo` option and `t.skip` call (all are platform or capability conditions) and every `existsSync` early return in test files (the directories they guard exist at this commit). Result: no row.

Not searched: behaviour a test asserts without naming it in its title or reaching it through a removed export; a full read of every assertion against the current code was out of this card's budget.
